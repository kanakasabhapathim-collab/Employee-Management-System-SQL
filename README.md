# Employee Management System (SQL)

## Overview
This project is a SQL-based Employee Management System developed using PostgreSQL.

## Features
- Database Creation
- DDL (CREATE, ALTER, DROP)
- DML (INSERT, UPDATE, DELETE)
- DQL (SELECT, WHERE, ORDER BY)
- DCL (GRANT, REVOKE)
- TCL (BEGIN, COMMIT, ROLLBACK, SAVEPOINT)

## Tables
- abc_mployee
- abc_department
- abc_project

## Technologies
- PostgreSQL
- SQL
